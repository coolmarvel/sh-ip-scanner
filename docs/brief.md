# 프로젝트 브리프: sh IP Scanner

## 한 줄 정의

로컬 네트워크(LAN)의 서브넷 대역을 훑어 **살아있는 호스트의 IP·MAC·호스트명을 표로 보여주는
Windows 데스크톱 스캐너** — 기존에 쓰던 포터블 툴 `faIpScanner`(Delphi 제작)를 **C#/Avalonia로
재현**하면서 개발자 본인이 **C#을 학습**하는 것이 이 프로젝트의 두 축이다.

> 이 프로젝트는 결과물(스캐너)과 학습(C#) **둘 다가 목적**이다. 그래서 "가장 짧은 코드"보다
> "개념이 드러나는 코드 + 풍부한 개념 주석"을 우선한다 (→ `docs/adr/0002-stack.md`, `docs/writing-guide.md`).

## 문제와 사용자

- **문제**: 같은 네트워크에 지금 어떤 장비가 붙어 있는지(IP·PC명) 빠르게 확인하고 싶다.
  기존 `faIpScanner.exe` 로 잘 해왔지만, 그건 남이 만든 블랙박스 포터블 exe다. 동작 원리를 이해하고,
  내 손으로 다시 만들면서 C#이라는 새 언어와 데스크톱 개발 스택을 익히고 싶다.
- **실사용 맥락**: 실제 목적은 **전산 관리(IT 자산 파악)**다. 로컬 IP 가 자동으로 잡히고(예:
  `192.168.80.x` 대역), 그 대역의 PC 들이 지금 켜져 있는지·어느 부서 PC 인지(PC명)를 한눈에 본다.
- **미래 확장(배경)**: 나중에는 단순 조회를 넘어, **업무 시간 종료 후(또는 PC방처럼 특정 조건에서)
  대상 PC 들을 자동으로 종료·재부팅**할 수 있게 하고 싶다. v1 은 조회까지만 하되, 그 확장을
  염두에 두고 스캔 로직(대상 PC 목록)과 액션(향후 원격 제어)을 분리해 설계 여지를 열어둔다.
- **벤치마킹 대상**: `faIpScanner.exe` — 서브넷을 멀티스레드로 스윕하고, `SendARP`(iphlpapi)로 MAC을,
  역DNS로 호스트명을 채워 표에 뿌리는 클래식 LAN 스캐너. 우리 v1은 이 핵심 동작을 그대로 재현한다.
  (정적 분석 근거: `TCheckIPThread`·`TFindHostNameThread`·`TIdConnectThread`(Indy)·`SendARP`·`WSAStartup`·
  `cmd /c arp -d` 문자열 — Delphi VCL/Indy 기반 네이티브 Win32 x86 GUI. → `docs/adr/0002-stack.md` 맥락 참고)

| 유형 | 이 앱에서 하는 일 |
|---|---|
| 개발자 본인(단일 사용자) | 스캔할 IP 대역을 넣고 → 스캔을 눌러 → 살아있는 호스트 목록(IP·MAC·호스트명)을 표로 본다 |

## 핵심 시나리오 (v1.0 에 반드시 되어야 하는 것)

우선순위 순. "누가 무엇을 해서 무엇을 얻는다":

1. 사용자가 **스캔할 대역을 지정**한다 (예: `192.168.0.1 ~ 192.168.0.254`, 또는 CIDR `192.168.0.0/24`)
   → 앱이 유효성을 검증하고 스캔 대상 IP 개수를 알려준다.
2. 사용자가 **스캔을 시작**한다 → 앱이 대역을 **동시(병렬)로 핑 스윕**하며, 진행률과 함께
   응답하는 IP를 실시간으로 표에 추가한다.
3. 살아있는 IP 각각에 대해 앱이 **MAC 주소(ARP)** 와 **호스트명(역DNS)** 을 채워 넣는다.
4. 사용자가 **스캔을 중간에 멈출** 수 있다 (긴 대역/느린 네트워크 대비).
5. 결과 표를 **열 기준으로 정렬**해서 본다 (IP 순 / 응답 시간 순 등).

## 제약

- **플랫폼/형태**: **Windows 데스크톱 GUI 앱**. 완전 오프라인(로컬 네트워크만 사용, 외부 서버 없음).
  실시간성은 "스캔 중 결과가 점진적으로 채워지는" 수준.
- **기간/리듬**: 개인 학습 프로젝트 — 마감 없음. 한 걸음씩 개념을 이해하며 진행.
- **비용**: 0원. 유료 API·인프라·클라우드 없음. 전부 로컬.
- **기타**: 혼자 쓰는 도구(공개 서비스 아님). 인증·결제·계정 없음. **본인이 관리·소유한
  네트워크의 자산 파악(네트워크 관리/방어) 용도** — 허가 없는 타 네트워크 스캔은 범위 밖.

## 성공 기준

> "이것만 되면 v1.0" — 사용자 기준 그대로:
>
> **저 `faIpScanner.exe` 처럼, 대역을 넣고 스캔하면 살아있는 IP가 MAC·호스트명과 함께 표에 뜨는 것.**
> 그리고 그 과정을 통해 C#의 핵심(비동기, 스레딩, P/Invoke, MVVM)을 코드로 이해하는 것.

## 범위 밖 (이번에 안 하는 것)

나중에 "이것도 되지 않나?" 가 나오면 여기가 스코프 방어의 근거다.

- **포트 스캔** (열린 TCP 포트 나열) — faIpScanner엔 있지만 v1 코어에선 뺀다. v2 후보.
- **MAC 제조사(OUI/vendor) 조회** — v2 후보 (OUI 데이터셋 동봉 필요).
- **결과 내보내기(CSV/JSON)** — v2 후보.
- **크로스플랫폼 실제 배포**(mac/Linux 인스톨러) — Avalonia라 기술적으론 열려 있으나, 이번 배포 타깃은
  Windows(Inno Setup)뿐. MAC 조회 등 일부 기능은 플랫폼 종속이라 추상화만 해두고 구현은 Windows 우선.
- **취약점/보안 스캔, OS 핑거프린팅** — 이 툴의 목적이 아니다. 순수 자산 발견까지만.
- **스캔 스케줄링·알림·히스토리 DB** — v1은 상태를 저장하지 않는 단발 스캔.
- **원격 종료/재부팅(자동 전원 관리)** — 실사용의 최종 목표. **이제 착수한다**(엔드포인트 에이전트).
  스캐너(관리자 콘솔) + 클라이언트 에이전트(트레이 상주, 자동 종료) 구조. 설계·단계는
  `docs/adr/0003-endpoint-agent.md` / `docs/plans/0002-endpoint-agent.md`. 안전장치(인증·부드러운 종료·감사) 내장.
