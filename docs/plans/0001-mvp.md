# Plan 0001 — MVP: LAN 스캐너 코어 재현

> 목표(브리프 성공 기준): **대역을 넣고 스캔하면 살아있는 IP가 MAC·호스트명과 함께 표에 뜬다.**
> 스택은 `docs/adr/0002-stack.md`. 상태 표기: `[ ]` 미착수 · `[~]` 진행 중 · `[x]` 완료 · `[?]` 결정 필요.

## 마일스톤 개요

| # | 마일스톤 | 완료 정의(사용자가 만져볼 수 있는 것) | 학습 포인트 |
|---|---|---|---|
| M0 | 스캐폴드 + 빈 창 | `dotnet run` 하면 Avalonia 창이 뜬다 | 프로젝트 구조, .csproj, 최소 MVVM |
| M1 | 바둑판 + 핑 스윕 | 로컬 IP 자동감지 → 검색 → 254칸 바둑판이 주황(사용중)/연두(사용가능)로 채워짐 | async/await, 병렬도 제한, 취소 토큰, ItemsControl 바인딩 |
| M2 | 호스트명(PC명) 조회 | 사용 중 IP 에 PC명이 붙는다(한글 포함) | NetBIOS UDP 질의, CP949 디코드, 역DNS 폴백, 인터페이스 |
| M3 | UX(확대·로그·종료) | 우상단 확대/축소, 검은 로그창, 종료 버튼, 아이콘 | Dispatcher 마샬링, 커맨드, 컨버터, LayoutTransform |
| M4 | 설치 패키징(라이센스) | `Setup.exe`(내 이름·라이센스 동의 페이지)로 설치→실행 | 자체포함 게시, Inno Setup, 라이센스/버전정보 |
| M5 | (미래) 원격 전원 관리 | 업무 종료 후 대상 PC 자동 종료·재부팅 | WMI/RPC, 권한·안전장치 (브리프 미래 확장) |

> **UI 방향 확정(2026-08-04 스크린샷 피드백)**: 초기 설계의 DataGrid 를 폐기하고 **원본과 동일한
> 254칸 바둑판(UniformGrid)** 으로 구현했다. 참고 이미지: `docs/feedback-archive/2026-08-04-ui-reference/`.
> MAC(SendARP) 는 사용자가 "IP 스캔 + PC명만" 이라 해서 **후순위**로 미뤘다(향후 확장).

## M1 — 바둑판 + 병렬 핑 스윕 `[x]`

- [x] `Converters/HostStateToBrushConverter` — 상태→색(흰/주황/연두)
