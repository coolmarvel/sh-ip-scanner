# 체인지로그 (릴리스 단위)

사람용 요약 — 릴리스(버전 승격·배포) 단위로만 기록한다. 세부 이력은 `session-log.md`.

> 저장소 **sh-pc-manager** (관리 콘솔 + 에이전트). **콘솔 명칭: sh IP Scanner → sh Manager**
> (에이전트 `sh Agent` 와 짝). IP 스캐너로 시작해 PC 전원 관리로 확장. 내부 어셈블리명 `ShIpScanner.*` 유지.

## 콘솔 v0.7.0 / 에이전트 v0.2.0 — 2026-08-05

- **콘솔 명칭 sh Manager** 로 변경(설정 저장 위치도 `%APPDATA%\sh Manager`).
- **관리자 일정 푸시**: 종료 시각은 **관리자만** 설정(콘솔 PC 제어 창 → `SetSchedule` 전송).
  에이전트는 일정을 **표시만**, 연장은 관리자가 허용한 경우에만 자체 연기(아니면 관리자 요청).
- **에이전트 설치관리자(0.2.0)**: 로그온 **자동시작** + **방화벽 인바운드 허용**(관리자 승인 반영).
  제거 시 방화벽 규칙 삭제 + 에이전트 종료.
- 인스톨러: `sh-manager-Setup-0.7.0` + `sh-agent-Setup-0.2.0`.

## 콘솔 v0.6.0 / 에이전트 v0.1.0 — 2026-08-05

- **엔드포인트 에이전트 도입** — 관리자 콘솔이 클라이언트 PC 를 제어(원격 종료·재부팅·잠금·메시지·연장·RDP).
- **에이전트(sh Agent)**: Windows 트레이 상주 앱. 업무시간 종료 시 **자동 종료(경고→저장유예→연장근무 연기)**.
  전용 아이콘·라이센스. 인증 토큰으로 보호.
- **콘솔**: 스캔 결과에 **에이전트 설치 배지**(파란 점) 표시, 살아있는 PC **더블클릭 → 제어 창**.
- **인스톨러 2종**: 콘솔(`sh-ip-scanner-Setup-0.6.0`) + 에이전트(`sh-agent-Setup-0.1.0`).
- 자동시작·방화벽 허용은 보안 민감 항목이라 분리(가이드 문서, 승인 후 반영).

## v0.5.0 — 2026-08-05

- **UI 정리 + 좌상단 아이콘 메뉴(옛 실행기 느낌)**: 아이콘을 누르면 **대역 관리·설정·정보** 메뉴.
  각 항목은 **모달 팝업**으로 열린다.
- **대역 관리 모달**: 대역 목록 + 추가/삭제(메인 화면에서 분리해 깔끔하게).
- **설정 모달**: 핑 타임아웃·동시 스캔 개수·PC명 조회 on/off (`settings.json` 저장, 다음 검색부터 적용).
- **정보 모달**: 제작자·라이센스·버전.
- **내 IP** 를 흐린 텍스트 → 잘 보이는 칩으로 재배치, 폰트/여백 정리.
- 기본 대역 오타 수정 **192.168.95 → 192.168.90**. 이전 설정에 95 가 저장돼 있으면 **자동 교정**(마이그레이션).

## v0.4.0 — 2026-08-05

- **여러 대역 드롭다운(관리자용)**: 스캔 대역을 드롭다운에서 선택. 기본 3개 대역(192.168.80/85/95)을
  시드하고, 자동 감지된 내 대역을 추가·선택. **대역 추가/삭제**(＋추가·삭제) 지원.
- 대역 목록은 `%APPDATA%\sh IP Scanner\subnets.json` 에 저장 — 관리자가 앱 또는 파일로 관리.
- 대역 형식 검증 + 단위 테스트 추가(9개). 자유 입력 IP 텍스트박스는 드롭다운으로 대체.
