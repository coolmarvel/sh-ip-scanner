# UI 참고 (2026-08-04)

원본 `faIpScanner` 스크린샷을 근거로 UI 를 구현했다. **실제 이미지 파일은 내부망 IP·부서 PC명이
찍혀 있어 git 에 포함하지 않는다**(로컬에만 보존, `.gitignore` 처리). 아래는 안전한 요약이다.

- **레이아웃**: 상단 헤더(제목·로컬 IP·검색 버튼) → 검은 로그창 → **1~254 바둑판**(15열).
- **색 규칙**: 흰=미확인(스캔 전) · 주황=사용 중(핑 응답, PC명 표시) · 연두=사용 가능(무응답).
- **로컬 IP 자동 감지** 후 그 `/24` 대역을 스캔.
- 피드백 반영: 콘텐츠 확대/축소 대신 **창 최소/최대/닫기(OS)**, 바둑판 **폭 맞춤**, 라이센스 **이성현**.

원본 대비 우리 구현은 `docs/plans/0001-mvp.md`(M1~M3) 및 `docs/changelog.md` 참고.
